# 진동 속도 측정 앱 (VibMeter)

진동연마 설비의 진동 속도(RMS mm/s)를 폰 가속도 센서로 측정하는 안드로이드 앱. 작성 H.G 박동원.

## 계산
- Z축 RMS 가속도 = 최근 3초 Z축 가속도의 표준편차 (중력 제외)
- 실측 주파수 = Z축 FFT 봉우리 (20~250Hz, 포물선 보간)
- **진동 속도 RMS (mm/s) = 159.15 × Z RMS ÷ 주파수**
- 참고 피크 (cm/s) = 22.5 × Z RMS ÷ 주파수
- 고정 상태: X·Y RMS 가 Z 의 20% 이하이면 양호
- 안정: 최근 3초(0.5초 간격 6개) 값이 ±5% 안

## 사용
1. 폰을 십자 가운데에 화면이 위로 오게 단단히 고정
2. 측정 시작 → "안정 — 기록해도 됩니다" 가 뜰 때까지 대기
3. 호기·스펙·설정 주파수·메모 입력 → 기록 저장
4. 엑셀로 내보내기 → 다운로드/VibMeter 폴더에 CSV 저장 + 공유
